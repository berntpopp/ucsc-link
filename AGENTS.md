# AGENTS.md — ucsc-link

Guidance for agents and contributors working in this repository.

> `README.md` is the front door and follows the **GeneFoundry README Standard v1** (hard
> ceiling 200 lines, fixed section order, machine-checked by `scripts/check_readme.py`).
> Depth lives in `docs/`. Do not grow the README: relocate.

## What this is

`ucsc-link` is a read-only MCP server over the official **UCSC Genome Browser JSON API**
(`https://api.genome.ucsc.edu`). It serves a curated allowlist of region tracks for hg38/hg19
plus bounded reference sequence. It is one backend in the GeneFoundry `-link` fleet, federated
behind `genefoundry-router` under the namespace **`ucsc`**. Scaffolding (MCP plane, Docker,
CI) was lifted from `metadome-link`.

## Two planes (non-negotiable boundary)

- **Data plane** — `config.py`, `tracks.py`, `ratelimit.py`, `api/`, `service.py`. Calls UCSC
  over async httpx, validates regions, returns **plain dicts**, raises typed
  `ucsc_link.exceptions` errors. Never builds envelopes.
- **MCP plane** — `mcp/`. `run_mcp_tool` (`mcp/envelope.py`) owns `success`/`_meta` and turns
  exceptions into **returned** `isError` envelopes (never raised to the client).

## Invariants

- **Live API only, no data snapshot.** Some UCSC tracks carry use restrictions; nothing is
  stored beyond the in-process TTL cache in `api/client.py`.
- **BLAT / isPcr are self-hosted** (`blat.py`, `blat_fetch.py`): UCSC's hgBlat/hgPcr are
  behind a human check — never try to bypass it. Kent binaries + `.2bit` are fetched at
  deploy time onto a volume, pinned by SHA-256 in `blat_fetch.PINS`, and never baked into
  the image (Kent licence: non-commercial only). `gfClient`/`gfPcr` run as subprocesses with
  argv lists, a timeout that kills the process group, and a concurrency semaphore. An
  undeployed assembly is `upstream_unavailable`, never a fake empty result.
- **Allowlist only.** Tracks come from `tracks.TRACKS`; the `TrackName` literal in
  `mcp/tools/region.py` must list the same names (guarded by `tests/test_tools.py`). Before
  adding a track, check `/list/tracks` (`protectedData` must be absent) and its description
  page for terms; record provider, terms and `non_commercial` on the `TrackSpec`.
- **Coordinates.** Machine fields are UCSC-native 0-based half-open; every region/record also
  carries a 1-based `display`. Assemblies are explicit; never lift over (vep-link does that).
- **Honesty.** `total` is exact or `null` (past `UPSTREAM_ITEM_CAP`), `truncated` is true
  whenever rows were withheld. Empty interval = success with `total: 0`; unknown chromosome =
  `not_found` (UCSC answers `200 []` for it, so chromosomes are validated first).
- **Politeness.** Every upstream request passes the process-wide `RateLimiter` (default 1/s,
  5,000/UTC day). Do not bypass it, including in live tests. The User-Agent names the product,
  version and project URL only — never user data.
- **Untrusted text.** Upstream prose (`TrackSpec.prose_fields`, search `label`/`description`)
  is fenced with `fence_untrusted_text`; upstream error bodies are only used to classify, never
  echoed (fixed messages in `api/client.py`).
- **6-code error taxonomy**: `invalid_input`, `not_found`, `ambiguous_query`, `rate_limited`,
  `upstream_unavailable`, `internal`.
- Tools publish no `outputSchema` (Tool-Surface Budget Rule 3); every input property has a
  description, required ones carry `examples`, closed vocabularies are `Literal` enums.
- Keep `mcp/capabilities.py::TOOLS` equal to the registered tool set and the README `## Tools`
  table in sync (both tested).

## Fleet deploy contract

`docker/docker-compose.npm.yml` (deployed by the fleet controller `strato_v6_docker_npm`)
declares `user: "10001:10001"` — this image's own uid:gid from `docker/Dockerfile`. `user` must
NOT appear in `docker/docker-compose.yml` / `docker/docker-compose.prod.yml` (the release gate
forbids it). Guard: `tests/unit/test_deploy_overlay_user.py`. Both reusable-workflow pins
(`container-ci.yml`, `container-release.yml`) track the same `genefoundry-router` revision.

Release checklist: bump `pyproject.toml`, `uv lock`, `CHANGELOG.md` heading
`## [x.y.z] - YYYY-MM-DD`, `CITATION.cff` `version:` (generated by the router's
`make citation-write`), tag `vx.y.z`, approve the `release` environment gate via
`gh api repos/berntpopp/ucsc-link/actions/runs/<id>/pending_deployments` (it can gate more than
once). **Never `gh release create`** — the workflow creates the immutable release.

## Definition of done

`make ci-local` green: format-check, lint-ci, lint-loc (≤500 lines/file), lint-readme,
lint-surface, mypy `--strict`, tests. Unit tests are network-free: `respx` replays recorded
UCSC responses from `tests/fixtures/ucsc/`; BLAT parsers replay recorded kent output from
`tests/fixtures/blat/`. Live checks are opt-in
(`make test-integration`, a handful of polite calls).

## Make targets

```
make install          # uv sync --group dev
make ci-local         # the definition-of-done gate
make test             # unit tests
make test-integration # live UCSC calls (opt-in, rate-limited)
make test-blat        # real Kent gfServer/gfClient/gfPcr on a tiny genome (CI runs it)
make dev              # unified HTTP server on 127.0.0.1:8000
make mcp-serve        # stdio MCP server
make docker-up        # Docker stack; make docker-url prints the MCP URL
```

## Conventions

- Python 3.14, `uv`, hatchling; structlog to **stderr only** (stdout is the stdio protocol).
- TDD: failing test first. Files under 500 lines.
- `tests/conformance/` and `scripts/check_readme.py` / `scripts/surface.py` are vendored
  byte-identical from `genefoundry-router`; do not edit them here.
